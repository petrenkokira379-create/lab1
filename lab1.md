### 1. Мета роботи
Набути практичних навичок зі встановлення та налаштування локального вебсервера (XAMPP), ознайомитися з базовим синтаксисом PHP та запустити перший файл у середовищі VS Code.

---

### 2. Технологічний стек
* **СУБД / Вебсервер:** XAMPP (Apache 2.0, PHP 8.3)
* **IDE / Редактор коду:** Visual Studio Code
* **Браузер:** Google Chrome

---

### 3. Хід виконання роботи

1. **Встановлення та запуск XAMPP:**
   * Завантажено та встановлено дистрибутив XAMPP.
   * У панелі *XAMPP Control Panel* успішно запущено модуль **Apache** (задіяні порти 80, 443).

2. **Розгортання робочої директорії:**
   * У директорії `C:\xampp\htdocs\` створено робочу папку проєкту `task_manager`.
   * Папку `task_manager` відкрито в редакторі коду Visual Studio Code.

3. **Створення PHP-скрипта:**
   * У папці `task_manager` створено файл `index.php`.
   * Вміст файлу `index.php`:

```php
<?php
  echo "<h1>Hello World! Це моя перша PHP-програма.</h1>";
  phpinfo();
?>
